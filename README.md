# VentaLocal

Aplicación móvil offline para gestionar clientes, productos y ventas, construida con Expo, React Native y TypeScript.

## Inicio rápido

```powershell
npm install
npm run start
```

Cuenta inicial de demostración:

- Correo: `admin@demo.com`
- Contraseña: `Admin123*`

Los datos se guardan únicamente en el dispositivo. Desde un perfil administrador, la opción **Restaurar datos locales** elimina los registros locales y vuelve a crear la cuenta inicial.

## Verificación

```powershell
npm run typecheck
npm run lint
npm test
```

> La autenticación local es apropiada para una demostración académica, no para un entorno productivo sin backend.
